# Self-hosted fonts

The default theme uses IBM Plex Sans (display + UI) and IBM Plex Mono. They are
vendored here so the status page paints without a third-party stylesheet -- the
documented deployment is an intranet Docker container, and a blocking Google
Fonts request stalls first paint on an air-gapped network (issue #28).

## Files

Two files, regenerated by [`scripts/subset-fonts.py`](../../../scripts/subset-fonts.py):

| File                       | Bytes  | SHA-256 (first 16)  | What                                                        |
| -------------------------- | -----: | ------------------- | ----------------------------------------------------------- |
| `ibm-plex-sans-wght.woff2` | 21 920 | `93e507f1180a8f1f` | IBM Plex Sans, **variable** (`wght` 100-700), one download for every weight |
| `ibm-plex-mono-500.woff2`  |  7 556 | `34f406ea03925a76` | IBM Plex Mono 500, the only mono weight shipped             |

Why this shape:

- The stylesheets ask for Sans at 300, 400, 500 and 600. As static files that is
  one download per weight; the variable font covers them all in one file that is
  smaller than two statics.
- No variable Plex Mono is published. The `@font-face` in `../tokens.css`
  declares the single 500 face for `font-weight: 400 600`, so the browser uses
  it as-is for every mono rule -- no per-weight download, no synthesised bold.
- Both are subset to what the UI can render: printable ASCII plus the symbols
  the components emit (`U+00A0`, `°`, `·`, `–`, `—`, `…`, `↑ → ↓`, `≥`). That is
  about half of fontsource's `latin` subset. A glyph outside the subset (an
  accented letter in a monitor name) renders from the fallback font for that
  character only; including the whole Latin-1 supplement would cost +16 kB.

No italics: the IBM Plex preset renders the display accents upright
(`--display-italic: normal`).

Vite content-hashes the files into `dist/assets/`, so they ride the same
immutable-cache path as the JS and CSS bundles. WOFF2 is already Brotli-compressed
internally, so no `.br`/`.gz` sidecars are generated for them.

## Regenerating

```bash
pip install fonttools brotli
python src/ts/deucalion-ui/scripts/subset-fonts.py
```

The script `npm pack`s the pinned fontsource packages (nothing is added as a
dependency), subsets them, writes the two files above and prints the sizes.
Update the table (and the `unicode-range` in `tokens.css` if the glyph set
changes) afterwards.

## Provenance

- `@fontsource-variable/ibm-plex-sans@5.3.0` -- `files/ibm-plex-sans-latin-wght-normal.woff2`
- `@fontsource/ibm-plex-mono@5.3.0` -- `files/ibm-plex-mono-latin-500-normal.woff2`

## The other families in the tweaks panel

Newsreader, Inter, JetBrains Mono, Space Grotesk and Space Mono are **not**
vendored. They are fetched from Google Fonts on demand, only after a user picks
them in the (console-summoned) tweaks panel -- see `google` in
`src/components/tweaks/fonts.ts`. The default page never contacts a third
party; on an air-gapped network those faces simply fall back to their stacks.
